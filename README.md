# Yang Binbin – Academic Homepage

Personal academic homepage for PhD application and research portfolio.

Live at: https://yangbinbin.github.io/ (after GitHub Pages is enabled)

## Structure

```
.
├── index.html          # Main page
├── style.css           # Stylesheet
├── images/
│   ├── avatar.jpg      # Profile photo (replace with your own)
│   ├── pub_tgrs2025.png  # Paper thumbnail
│   ├── logo_ncut.png   # NCUT logo
│   ├── logo_phd.png    # PhD institution logo
│   └── logo_undergrad.png
└── assets/
    └── CV_YangBinbin.pdf   # Your CV (add manually)
```

## Quick Start

1. Fork / clone this repo to `<your-github-username>.github.io`
2. Replace `images/avatar.jpg` with your photo
3. Add your CV at `assets/CV_YangBinbin.pdf`
4. Edit `index.html` to fill in `[TBD]` fields
5. Push → GitHub Pages auto-deploys
